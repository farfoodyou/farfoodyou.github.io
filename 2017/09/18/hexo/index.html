hexo的安装配置和常用命令

安装

# 安装hexo
npm install hexo -g  #-g表示全局安装, npm默认为当前项目安装
hexo version
# 初始化博客文件夹
hexo init blog
# 切换到该路径
cd blog
# 安装hexo的扩展插件
npm install
# 安装其它插件
npm install hexo-admin --save
npm install hexo-deployer-git --save
npm install hexo-generator-sitemap --save

管理

hexo-amdin可以让博客可视化编辑
需要hexo配置文件最后添加

admin:
  username: myfavoritename
  password_hash: be121740bf988b2225a313fa1f107ca1
  secret: a secret something

网上很多都是不加deployCommand的，结果就是deploy的时候出现错误
改了index.html中居然加载jquery官方的一个js文件，难怪每次打开都很慢，我自己下载了
参考了别人的代码，改动了spwan语句，才可以在win下deploy.

这个password_hash是一种 bcrypt hash of your password，是一种安全的加密方式，那我怎么获得呢？如下步骤：

$ node
> const bcrypt = require(&apos;bcrypt-nodejs&apos;)
> bcrypt.hashSync(&apos;your password secret here!&apos;)
//=> &apos;$2a$10$8f0CO288aEgpb0BQk0mAEOIDwPS.s6nl703xL6PLTVzM.758x8xsi&apos;

Hexo常用命令：

hexo new "postName"       #新建文章
hexo new page "pageName"  #新建页面
hexo generate             #生成静态页面至public目录
hexo server               #开启预览访问端口（默认端口4000，&apos;ctrl + c&apos;关闭server）
hexo deploy               #将.deploy目录部署到GitHub

当然，如果每次输入那么长命令，那么一定想到用简写：

hexo n == hexo new
hexo g == hexo generate
hexo s == hexo server
hexo d == hexo deploy

其它的，还可以复合命令：

hexo deploy -g
hexo server -g

有时候生成的网页出错了，而生成的rss其实没有清除，那么用下面的命令，在重新生成吧
hexo clean
