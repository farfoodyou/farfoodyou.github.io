Claude 3.7 Sonnet：一个模型两种模式，外加一个终端 agent

2025-02-25·6 分钟·2500 字 模型

2 月 24 日，Anthropic 同时发了 Claude 3.7 Sonnet 和 Claude Code。前者是市面上第一个混合推理（hybrid reasoning）商用模型，后者是一个跑在终端里的 agentic coding 工具（当时是 limited research preview）。

这篇主要说前者，因为它回答了一个当时很实际的问题：要不要为推理单独维护一条模型线？

混合推理：一个 checkpoint，两种行为

o 系列和 R1 的做法是“推理模型 = 独立模型”：o1/o3-mini 和 GPT-4o 是两套权重、两套行为、两套定价。Claude 3.7 的选择是同一个模型：

  • 普通模式：接近即时的回答，行为和 3.5 Sonnet 类似；
  • extended thinking 模式：先输出一段可见的思考过程，再给答案。

官方措辞是 “the first hybrid reasoning model on the market”，思考内容对用户可见。这一点和 o1 初期隐藏 CoT 形成对照——可见性的好处是调试和审计，坏处是用户可能被中间过程的措辞误导（那只是草稿，不是结论）。

思考预算是一个整数参数

官方文档里，API 侧的接口非常“工程师友好”：不是开关，而是一个 token 上限。

resp = client.messages.create(
    model="claude-3-7-sonnet-20250219",
    max_tokens=32000,
    thinking={"type": "enabled", "budget_tokens": 16000},  # capped by max_tokens
    messages=[{"role": "user", "content": "why does this code deadlock?"}],
)

官方说明里有两个要点（原文）：

  1. 预算 N 最大可以取到输出上限，即 128K token；
  2. 思考 token 按输出 token 计费，价格和 3.5 Sonnet 一致：\$3 / \$15 每百万 token。

第二点很关键：不涨价是一种策略。它等于告诉用户“推理不是奢侈品，是同一商品的不同规格”。对照 o3-mini 的 1.10/4.40，两家都在用价格把“思考”从旗舰能力降成标准件。

数字：赢在 agent 任务

官方给的 SWE-bench Verified（真实 GitHub issue）结果，口径写得很清楚：

口径 分数
无 scaffold（单次尝试）63.7%
自建 scaffold（n=489 子集，多次采样 + 打分重排）70.3%

同一篇里还提到 TAU-bench（带工具交互的 agent 基准）达到 SOTA。这两个基准的共同点是多轮、有工具、有环境反馈，而不是单轮问答——选这两个当主指标，本身就说明它在往 agent 方向押注。

一个容易被忽略的细节：70.3% 是“多次采样 + 用打分模型重排”的结果，且只在 n=489 的子集上。榜单数字和 scaffold 强相关，横评时如果不看 scaffold 描述，结论基本不可用。

Claude Code 才是重点

同一天发布的 Claude Code 是个命令行工具，能在终端里读代码、改文件、跑测试、提交。当时的定位是研究预览，但方向很明确：把 agent 放进开发者已有的工作流，而不是再做一个 IDE。

从工程角度看，这类工具对模型的要求和聊天完全不同：

  • 需要长上下文（读多个文件）；
  • 需要可靠的工具调用和错误恢复（命令失败要能自己看输出、改命令）；
  • 需要“少说话多干活”的输出风格，否则 token 成本爆炸；
  • 需要可中断、可回滚（改错了要能撤销）。

这些能力没法靠刷 MMLU 得到。2025 年之后模型竞赛的重心从“知识”转向“agentic 任务”，Claude 3.7 + Claude Code 这个组合算是提前踩了点。

混合模式的工程代价

站在自建推理服务一侧，混合模式不是免费的：

  1. KV cache 复用变差。 思考段落的长度不确定，前缀缓存命中率下降；同一模型两种长度分布，batch 的长尾更明显。
  2. 训练侧要两种分布都见。 只训长 CoT 会让普通模式变慢变啰嗦，只训短回答又学不会长推理，配比成了新变量。
  3. 评测要分模式。 同一个模型开与不开思考是两个产品。

反过来说，混合模式省掉了维护两条模型线的成本：一套权重、一套安全评估、一套部署。对供应商是笔划算的买卖：思考从“选模型”变成“传参数”，独立推理模型线更像过渡方案。

判据只有一条：同一个 checkpoint 在两种模式下的分数必须分开报，合报会把这个变量藏进产品文档里——SWE-bench 63.7% 和 70.3% 是同一个权重在两个 scaffold 下的结果，对外只写一个数就是误导。
