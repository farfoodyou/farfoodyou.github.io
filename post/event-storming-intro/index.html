事件风暴入门：一场会能产出什么

2020-08-20·6 分钟·2262 字 架构

目录

  4. 不能产出什么

用白板加文档讲订单流程，常见的结局是这样：产品讲流程，后端问「这一步谁写库」，两个小时后白板上是一张谁都不认的流程图。换成另一种形式：一面四米长的墙、五种颜色的便利贴、不许开电脑。三个半小时之后，墙上是一条九十多个事件的序列，和七个红点。

事后看，差别不在方法论，在约束。贴纸是物理对象：写不下细节、不能重叠、撕掉留痕、一面墙只放得下一条主线。这些约束把一场讨论会变成了有边界的设计活动。

四类贴纸与争议标记

贴纸 颜色惯例 写法 反例
领域事件橙过去式 + 业务名词「处理订单」
命令蓝祈使句 + 发起者「订单流程」
聚合 / 角色黄名词，谁保证这条不变式「订单服务层」
读模型 / 外部系统绿只标名字，不展开「各种查询」
争议红「这里说法不一致」+ 责任人无

事件是这套方法里唯一有严格语法的东西：过去式、业务语义、已发生。「订单已提交」是事件；「订单创建中」是状态；「写入订单表」是实现；「同步数据」没有业务主语。死抠语法的理由是：事件是唯一能被业务方和后端同时验证的贴纸——业务方判断「这件事到底会不会发生」，后端判断「这件事发生时哪张表被改」。命令和聚合都会引战，事件不会。

物理约束不是仪式感

用在线白板复现同一场会，产出明显更差，逐条对得上：

约束 逼出来的行为 在线白板的反例
墙的长度只容一条主线，第二条另起一面无限画布，十分钟满屏都是框
一张贴纸写不下二十字逼出一句话事件，细节被踢出会议文本框能塞一整段需求
时间轴从左到右顺序即语义，乱序与并发当场可见拖拽自由，顺序靠猜
不能撤销，撕掉留痕争议可见删掉就没了
站着、限时收敛坐着开三小时没有结论

最有用的是「写不下」。任何需要三行才能说清的东西，说明它不是事件，而是一条规则或一个流程，应该留到建模阶段再展开。事件风暴一半的价值来自拒绝记录细节。

一场会能产出什么

把墙上的东西落成机器可读的清单，是会后最值钱的一小时——不落，墙就只是一张照片。

# command -> events，附发起者与聚合候选；红点另开一节
aggregate_candidates: [order, payment]   # 会上只标名字，不展开内部结构
timeline:
  - command: submit_order
    actor: buyer
    events: [order_submitted]
    aggregate: order
  - command: pay_order
    actor: buyer
    events: [payment_authorized, order_paid]
    aggregate: payment        # 红点：payment 与 order 谁负责「已付」？
  - command: close_order
    actor: scheduler
    events: [order_closed]
    aggregate: order
    note: 与 pay_order 竞争同一状态，需定序

这份清单不是设计文档，它给下一场会提供输入：每个 command 的 actor 是权限模型的起点，每个 event 的 aggregate 是事务边界的候选，红点是议程。除此之外还能拿到三样东西：术语表（同一个概念在会上被叫了三个名字时当场统一）、边界候选（事件序列里粒度突变的地方通常是上下文接缝）、以及争议清单，这张单子比模型图值钱，因为它带责任人。

读模型的绿贴纸单独归成一列：把「谁要看什么」和「谁改什么」分开放，后面拆查询侧的时候不用重新开会。CQRS 在墙上的位置就是这一列绿贴纸，不是另一种架构风格。

不能产出什么

事件风暴不产出聚合内部结构、字段、库表、接口定义、排期。硬要在一场会里产出这些，结果是所有人开始讨论索引和分库，事件序列停止生长。

也不要把系统事件混进业务事件。重试、超时、日志落盘、消息投递，这些在墙上没有位置：它们会让时间轴退化成调用链。判断标准只有一条，这条事件业务方会不会关心。不会，就不贴。

失效模式与量级

失效模式 症状 处理
变成需求评审产品开讲，其他人不说话主持人只接受过去式贴纸
人太多八人以上开始有人当观众上限八人，业务与工程各半
不收敛三小时还在第一条主线打转六十分钟必须走完一条端到端主线
粒度失控「已写入」「已返回」都成了事件一个业务动作只允许一个事件

量级参考（经验值，三小时一场会）：三小时、八个人、一条端到端主线，能产出 60–120 个事件；超过 150 个基本是把系统事件或字段级变化混了进来；少于 30 个通常是粒度太粗，比如把整个「下单」写成一个事件。

还有一条判据：会后若没法用墙上的事件回答「这笔钱从哪一步开始不可逆」，那这场会只是把流程图换了个贴法。
